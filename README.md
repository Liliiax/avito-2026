# Avito — кандидатогенерация для поиска услуг

Решение задачи **candidate generation**: по поисковому запросу отобрать до 50 наиболее релевантных объявлений-кандидатов. Метрика — **Recall@50**.

## Подход

Используются два независимых лексических поиска:

* **Word TF-IDF** — поиск по словам и биграммам;
* **Character TF-IDF** — поиск по символьным n-граммам, более устойчивый к опечаткам и различиям в написании.

Из каждого поиска берётся по **500 кандидатов**, после чего результаты объединяются с помощью **Reciprocal Rank Fusion (RRF)**. Из объединённого списка выбираются итоговые **top-50** объявлений.

Для экономии памяти запросы обрабатываются батчами, а TF-IDF-матрицы хранятся в sparse-формате.

## Параметры

Основные параметры находятся в начале `answer.py`:

* `TOP_K = 50` — количество итоговых кандидатов;
* `WORD_TOP_K = 500` — кандидаты из Word TF-IDF;
* `CHAR_TOP_K = 500` — кандидаты из Char TF-IDF;
* `QUERY_BATCH_SIZE = 100` — размер батча запросов;
* `WORD_MAX_FEATURES = 250_000`;
* `CHAR_MAX_FEATURES = 180_000`;
* `RRF_K = 60`.

## Запуск

Данные уже должны находиться в папке `data/`.

Из корневой директории проекта достаточно выполнить:

```bash
python answer.py
```

После выполнения в корневой папке появится файл:

```text
answer.csv
```

В нём находятся колонки `query_id` и `answer`, где `answer` содержит до 50 `item_id`, разделённых пробелом.
